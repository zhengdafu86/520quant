# 520 战法量化策略说明（供专业人士点评）

> 一句话概述：基于 **MA5 / MA20 双均线** 的 A 股**趋势跟随波段**策略。
> 收盘后全市场扫出买点候选 → 次日**盘中实时确认**才买入 → 持有期间动态止损止盈。
> 只做**主板**（无创业板/科创板权限），模拟盘运行，最多同时持有 6 只。

---

## 一、选股（每日收盘后全市场扫描）

### 1. 股票池范围
- 沪深**主板**全部股票；**剔除创业板(30开头)、科创板(688)**（账户无权限）。
- 剔除：ST/退市/次新股、停牌。

### 2. 基础门槛
- 股价 5–200 元；日成交额足够（流动性）；流通市值 30–800 亿；市盈率 ≤200 且非亏损；上市满 60 个交易日。

### 3. 三类买点信号（核心）
| 信号 | 通俗含义 | 关键条件 |
|---|---|---|
| **金叉** | 短期均线刚向上穿过中期均线，趋势启动 | MA5 上穿 MA20 + 放量(量比≥1.5) + 收盘站上 MA20 |
| **回踩** | 上升趋势中股价回调到 MA20 支撑、企稳 | MA20 向上 + 此前有过金叉 + 股价贴近 MA20(±3%内) + **缩量回调** 或 **针形支撑** |
| **粘合发散** | 均线长期缠绕后放量突破，爆发力强 | MA5 与 MA20 粘合多日后，放量金叉并突破前期压缩区高点 |

- **金叉"转头豁免"**：MA20 还没正式走平转上、但跌幅快速收窄（拐点），且近 2 日出现金叉、收盘站上 MA20，也放行——避免漏掉趋势刚启动的买点。
- **回踩质量收紧**：必须是**缩量回调**（浮筹清洗）或**针形支撑**（盘中跌破 MA20 又被买回、收阳线，且量比≤2.5 排除巨量博弈）；若信号日股价已涨超 5%，视为反弹走完、**信号作废**。

### 4. 大盘前提（仓位总开关）
- 仅当**沪深300 指数 MA20 > MA60**（大盘自身处于多头）时才允许新建仓；否则**空仓观望**。

### 5. 打分与精选
- 每个候选打 0–100 分：形态强度、量能、**贴近 MA20（盈亏比）**、趋势斜率、RSI、换手率趋势、**相对沪深300强弱** 综合加减分。
- 输出当日候选清单，并高亮 **"精选 Top8"**（质量分最高的 8 只），供仓位有限时优先挑选。

> **例（选股）**：某主板股票今日缩量回调到 MA20 上方 1%、MA20 持续向上、20 日跑赢沪深300、收阳——被识别为"回踩买点"，质量分 92，进入精选 Top8。

## 二、买入（次日盘中实时确认，不是收盘信号直接买）

收盘选出的候选**不会无条件买入**，而是次日进入实时监控，**盘中逐条确认**后才下单。

### 买入时间窗
- 金叉/回踩：**10:00–11:30 / 13:30–14:30**
- 粘合发散：**9:45** 起（突破信号时间敏感，提前）
- 14:30 后不再新建仓。

### 盘中确认条件（须全部满足）
1. 在买入时间窗内；
2. 未跌停（能成交）；
3. 开盘跳空不过大（金叉/粘合跳空 ≤ -3%、回踩 ≤ -4% 则当日信号作废）；
4. 当日涨幅未过高（回踩 ≥+5%、金叉/粘合 ≥+8% 则不追）；
5. **不弱于大盘**（相对强弱达标）；
6. 当日振幅 < 5%（筹码稳定）；
7. **价格站上 MA20，且不超过 MA20×1.05**（追高保护）；
8. 站上 MA5（金叉/粘合；回踩豁免此项）；
9. **5 分钟K线近 3 根站稳 MA20 且趋势向上**；
10. 量比 ≥ 1。

### 仓位与优先级
- 最多同时持有 **6 只**；每"格"资金 ≈ 总资金 / 6。
- 仓位大小按信号：**粘合 1.5 格、金叉/回踩 1 格**。
- 当候选多、仓位不够时，**买入优先级**：① 粘合优先 → ② **盈亏比优先（离止损越近、风险越小越先买）** → ③ 手动标记的 P1/P2/P3 → ④ 评分。
- **T+1**：当日买入，**次日**才能卖出。

> **例（买入）**：上例回踩股次日 10:15，价格在 MA20 上方 0.8%（未追高）、5 分钟K连续 3 根站稳 MA20 且走高、量比 1.1、不弱于大盘——确认买入；因离止损（MA20 下方）仅 0.9%，盈亏比好，被优先于其他候选成交。

## 三、卖出（持仓期间每 30 秒检查一次）

### A. 止损（任何时间立即执行）
- **硬止损**：浮亏 ≥ 5%；
- **趋势止损**：跌破 MA20 且 5 分钟K连续 2 根确认跌破；
- **止损价**：触及止损价（含下方追踪抬升后的价位）。

### B. 追踪止损（止损线只升不降，逐级锁定利润）
| 浮盈达到 | 止损线（保底）抬到 |
|---|---|
| ≥ 5% | 保本（成本价） |
| ≥ 10% | +5%（并跟随 MA5） |
| ≥ 20% | +13% |
| ≥ 30% | +20% |

### C. 止盈
- **接近涨停锁利**：当日涨 ≥9% 且盈利时——金叉/回踩当日即锁利；**粘合发散首个涨停日不卖**（给龙头续航），次日再涨停才锁（立即执行）；
- **RSI 超买**：近 3 日 RSI 有 2 日 >80 且从峰值回落 ≥2 个百分点（动量见顶，立即执行）；
- **死叉止盈**：MA5 跌破 MA20（趋势结束）且盈利；
- **浮盈回落保护**：从浮盈峰值回落超过容忍度（粘合 8pp / 金叉 5pp / 回踩 3pp）；
- **峰值锁利**：浮盈冲高后回落到锁定线（粘合 12% / 金叉 10% / 回踩 8%）。
- 其中"死叉、浮盈回落、峰值锁利"这三类**非紧急止盈集中在 14:30–15:00 执行**，避免被日内噪音过早洗出。

### D. 交易成本
- 佣金 万分之 3（买卖双边）+ 印花税 千分之 1（卖出）。

> **例（卖出）**：上例买入后涨到 +12%，止损线自动从"MA20 下方"抬到"成本 +5%"并跟随 MA5；随后冲到峰值 +13% 又回落到 +8%（回踩信号容忍 3pp，已超），在 14:30 后触发"浮盈回落保护"卖出，锁定约 +8% 收益。

## 四、回测情况（截至目前，供参考）

> 用全主板无偏样本回测（已扣佣金+印花）：

- **牛市段（约1年，沪深300 +22.9%）**：策略约 +57%（无滑点）/ +23%（含0.1%滑点），跑赢指数；
- **熊市段（2023下半年，沪深300 -18.6%）**：策略约 **-9.7%**（靠大盘过滤 83% 时间空仓，亏损约为大盘一半）。
- 特征：胜率约 40–50%，**靠"截断亏损 + 让利润奔跑"（盈亏比约 2）盈利**，是典型趋势跟随曲线。

## 五、已知待商榷点（请重点点评）

1. **对滑点/成交价敏感**：交易偏频繁、单笔利润薄，0.1% 滑点就会显著削弱超额收益。是否应**降低换手、拉长持有**？
2. **盘中确认筛掉约一半日线信号**：实盘只买入约 50–60% 的扫描信号，这种"挑剔"是利大于弊还是错失机会？
3. **追高/进场时机**：当前用"站上 MA20 + 5分钟趋势向上"确认买入，是否偏晚或偏早？回踩的涨幅闸(+5%)、追高保护(MA20×1.05)阈值是否合理？
4. **止盈是否过早/过晚**：14:30 集中止盈、峰值回落容忍度、追踪止损档位（5/10/20/30%）是否符合 A 股节奏？
5. **大盘过滤**用沪深300 的 MA20>MA60，是否够灵敏 / 会否在震荡市频繁空仓踏空？
6. **选股优先级**改成了"盈亏比优先"（买离止损最近的），而非评分高低——这个取舍是否合理？
